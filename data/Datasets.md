# Required Input Data Files

This folder contains **simulated datasets** designed to replicate the structure and format of the confidential data used in the analysis. These datasets are provided solely for demonstration and testing purposes, and **do not reflect real-world values**. As a result, any outcomes or results obtained using these datasets will **differ from those presented in the original study**.


## 1. `city_list.RData`

- **Format**: Data frame with metadata for multiple cities
- **Purpose**: Used in `1.FirstStage.R`
- **Required columns**:
  - `regionnm`: Region name
  - `countrynm`: Country name
  - `citynm`: City name
  - `gdp`: Country-specific average GDP

> Note: This sample dataset was created with the same regions(10) and countries(26) as the original data. Since the original data cannot be shared, **two arbitrary city names** were generated for each country. The dataset includes `region`, `country`, and `city` columns for demonstration purposes only. `gdp` column represents the country-specific average gross domestic product per capita in U.S. dollars from 2000 to 2014 (provided by the OECD Region and Cities database; URL: http://stats.oecd.org/) 

---

## 2. `slist.RData`

- **Format**: R list object
- **Each element**: A data frame corresponding to a city
- **Required variables**:
  - `date`: Date (class: `Date`)
  - `tmean`: Daily mean temperature (numeric)
  - `stot`: Daily total suicide count (integer)

> The dataset covers a **synthetic daily time series** from **January 1, 1990 to December 31, 2010**, which differs from the original study period.
> For each city, daily records include:
> - Simulated suicide count ranging from 0 to 10(`stot`)
> - Simulated mean temperature (`tmean`)
>   - Regional average temperature (mean and SD)
>   - Sinusoidal seasonal variation
>   - Random noise to simulate day-to-day fluctuation

---

## 3. Climate Scenario Data (`ssp126.RData`, `ssp245.RData`, `ssp585.RData`)

- **Format**: Data frame
- **Columns**: Modeled temperature time series for each city
- **Purpose**: Used in `4.ProjectionANAF.R` to project future suicide mortality under different climate change scenarios

> These datasets were generated by randomly selecting geographic coordinates within each country to represent hypothetical city locations.
> Synthetic temperature time series were simulated for each Shared Socioeconomic Pathway (SSP) scenario—SSP1-2.6, SSP2-4.5, and SSP5-8.5—to reflect plausible long-term warming trends associated with different emissions trajectories. 
> The values are entirely artificial and do not correspond to real ISIMIP climate model outputs (GFDL-ESM4, IPSL-CM6A-LR, MPI-ESM1-2-HR, MRI-ESM2-0, UKESM1-0-LL).

All datasets in this folder are **simulated and anonymized**.
